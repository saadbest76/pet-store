# PetStore

A simple pet store built with Next.js 14, TypeScript and Tailwind CSS.

## Features
- Responsive design with Tailwind CSS
- Product catalog with categories and search
- Product detail pages
- Shopping cart with add, remove and update
- Mini cart drawer in the navbar
- Simple checkout placeholder

## Development

```
npm install
npm run dev
```

## Build

```
npm run build
```
